# 05. UI Mockups

Tài liệu này dành cho các bản thiết kế giao diện (wireframe/mockup).

## Trạng thái hiện tại
Chưa có mockup cụ thể. Sẽ bổ sung sau bằng ảnh PNG/JPG hoặc link Figma.

## Màn hình dự kiến

### Inventory (PC/PWA)
- Dashboard tổng quan tồn kho
- Danh sách sản phẩm
- Form nhập kho (purchase) — bao gồm chọn batch/lotCode/expDate
- Form chuyển kho (transfer) — bao gồm chọn batch bắt buộc
- Báo cáo tồn theo kho
- Báo cáo tồn theo batch (highlight sắp hết hạn / âm kho)
- Danh sách hàng sắp hết hạn

### POS (Mobile / React Native)
- Màn hình bán hàng chính (quét barcode / tìm sản phẩm)
- Giỏ hàng — hiển thị batch đã auto-pick (FEFO), cho phép sửa
- Cảnh báo sắp hết hạn (inline trong giỏ)
- Cảnh báo âm kho (inline hoặc modal)
- Màn hình thanh toán
- Lịch sử đơn bán
